# 掌心论坛存档 · Discourse

导出于 2026-09-22，在论坛关闭之前。

## 里面有什么

- `论坛存档.md` —— 人能直接读的一份：15 个主题、28 条发言，按时间顺序，原文照录未作编辑
- `论坛存档.json` —— 结构化数据（主题 id、标题、每条发言的作者与时间）
- `json/` —— 每个主题的原始 API 响应，最完整，将来若要再处理以它为准
- `uploads/` —— 帖子里的 3 张原图（书法、音乐封面等），原始分辨率

## 为什么不是官方备份

这个论坛在 **Free Plan** 上，后台不提供「创建并下载备份」——备份页写明异地备份由 Discourse 每 12 小时自行生成，需要时联系他们索取，自助下载不可用（列表显示「无可用备份」）。
所以这份存档是通过论坛的公开 API 逐主题抓取的。**文字与图片是全的**，但不含用户账号、私信、站点设置。

## 与官网「诗海流风」的关系

官网只迁入了**每个主题的首帖**，共 14 帖（另有 1 帖是 Discourse 建站样板，未迁）。
**回帖没有迁**——本存档里的 28 条发言减去 15 个首帖，其余 13 条回帖只存在于这里。
